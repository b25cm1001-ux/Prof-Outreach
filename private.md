# Privacy Policy: Prof Outreach

Prof Outreach is a personal tool used only by its developer, Abhishek Reddy,
to send his own research-internship emails and to check his own mailbox for replies.

- It accesses only the developer's own Gmail account, using the permissions
  gmail.send and gmail.readonly.
- It does not collect, sell, share or transfer any user data to third parties.
- Email data is processed only to send messages and detect replies, and is stored
  only in the developer's private repository and local files.
- No other users are served by this app.
